# Атлас тамагочи

Русскоязычная фанатская энциклопедия Tamagotchi и личная коллекция Paradise.

Основной сайт: https://tamawikia.ru/

Домен `tamawikia.online` обслуживается отдельным репозиторием `intercontinentalmassacre/tamawikia-redirect` и перенаправляет посетителя на основной адрес, сохраняя путь, параметры и ссылку на раздел. Перенаправление выполняется в браузере; это не серверный HTTP 301.

DNS обслуживает Рег.ру, сайт и HTTPS — GitHub Pages. После изменения DNS нужно дождаться проверки домена и выпуска сертификата, затем включить Enforce HTTPS в настройках Pages обоих репозиториев.

## Разработка

Сайт полностью статический. HTML, стили и JavaScript находятся в `dist/index.html`, статьи — в `dist/wiki/`, изображения — в `dist/gallery-assets/`. Сборка и зависимости не требуются.

Для локального просмотра: `python3 -m http.server 8000 --directory dist`, затем открыть http://localhost:8000/.

Изменения в ветке `main` автоматически публикуются в GitHub Pages через `.github/workflows/pages.yml`.

## Личная коллекция

Отметки сохраняются в localStorage браузера, отдельно для каждого адреса сайта. Данные со старого домена ChatGPT Sites автоматически не переносятся. Общей базы пользователей и серверной части нет.
